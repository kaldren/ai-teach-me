# AI, Teach Me!

**Stop coding blind with AI.** When Claude suggests a framework, library, database or tool and you accept it,
you often end up using something you don't really understand. This Claude Code plugin fixes that: for every
technology you adopt, it writes a short Markdown learning note covering what it is, why it was chosen for your
project, its key concepts, common pitfalls, alternatives and links to the official docs. Over time the notes
become your own reference for your whole stack.

## Install

In Claude Code:

```
/plugin marketplace add kaldren/ai-teach-me
/plugin install ai-teach-me@ai-teach-me
```

Pick the **user** scope so the plugin works in every project. When asked for the knowledge base folder, leave
it empty to use `ai-teach-me-kb` in your Documents folder.
